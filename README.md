One of my favorite games of all time is Megaman Starforce, which was originally released a three game series (7 variations between the three) that was then remastered for the Switch 
One of the core aspects of the game is card collecting: Standard, Mega, and Giga class cards
To get to 100% Completion you need to collect all the cards in the games
Knowing the locations for them as well as how to obtain is hard
I used to look it up or go to YouTube, the problem is there is a lot of searching still involved in that and I wanted to make it faster as well as streamlined
That is why I decided to make a whole code that could read a spreadsheet with all the information that I could ask the code to read and give back the information I request
I think it will make card hunting a lot more efficient, it will take some work to craft the code as well as the excel workbook that will accompany it, but it will make card finding a lot easier for the future
Who knows, if it goes well, maybe I'll expand the code to give help requests, cipher mail codes, tips, and even information on the completion stars, but first this is going to be a code for card finding

All sources will be linked of where I got all the card info, but first I need to finish it as well as the code, but the journey will be documented here, so stay tuned and if you are a Megaman Starforce fan, I hope this helps you
